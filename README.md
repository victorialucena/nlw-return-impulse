## 🚀 NLW Return – Impulse

Projeto desenvolvido durante o evento **NLW Return – trilha Impulse** da [Alura](https://www.alura.com.br/), promovido pela **Rocketseat**.

O projeto é um **widget de feedback**, que permite aos usuários enviarem sugestões, elogios ou relatarem problemas diretamente pela interface de um site ou aplicação.

### 💡 Funcionalidades:
- Componente de feedback interativo e reutilizável
- Captura do tipo de feedback (problema, ideia, ou outro)
- Upload de screenshot da tela
- Envio de feedback com título e comentário
- Design moderno e responsivo

### 🛠️ Tecnologias utilizadas:
- React
- TypeScript
- Tailwind CSS
- Headless UI
- Vite
- Mobile usando React Native
